Dominus Optimizer is an experimental system optimization tool for Windows and Linux. It is currently in a very early stage of development, so features may be incomplete or change over time.

Features include:

    System debloating
    Virus and malware scanning
    Storage scanning
    RAM cleanup
    Graphics card and processor options
    Internet optimization options

Linux support is still in development.

Use this early version with caution and make sure to back up important data.
